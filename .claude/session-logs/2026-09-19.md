### Blank web screen #1 — `import.meta`
- User reported blank `localhost:19006`. Bundle compiled fine; headless Edge console showed `Uncaught SyntaxError: Cannot use 'import.meta' outside a module`.
- Cause: `zustand/middleware` ESM build contains `import.meta.env` (devtools code); Metro's web bundle is a classic script.
- Fix: `app/babel.config.js` with `presets: [['babel-preset-expo', { unstable_transformImportMeta: true }]]`, restart Expo with `--clear`. Page then rendered "Login".
- Also found the user had commented out `(auth)/_layout.tsx` while debugging (route dropped, "missing default export" warning); restored the plain stack version.

### AsyncStorage version + blank web screen #2 — stale Metro cache
- `npx expo install @react-native-async-storage/async-storage` pinned it to `2.2.0` (SDK 54's version; plain npm had installed 3.1.1).
- Afterwards the user hit a blank page again with `blocked due to MIME type ("application/json")`. The bundle request returned Metro's JSON build error: `Unable to resolve module merge-options` (installed at repo root, but Metro's map predated the downgrade). Fixed by restarting Expo with `--clear`; page renders "Login", console clean.
