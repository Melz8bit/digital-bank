## Auto-logout on an invalid session (built by Claude on request)
- `/pin/verify` is authenticated and returns 401 for a **wrong PIN**, so "log out on any authed 401" would have logged the user out on every mistyped PIN.
- `requireAuth`'s three 401s now send `code: 'SESSION_INVALID'`. `handleResponse()` in `app/lib/apiClient.ts` calls `logout()` only for a 401 with that code, then throws "Your session has expired. Please log in again." Clearing the token flips the `Stack.Protected` guards, which sends the user to Login.
- New `app/lib/logout.ts`: `clearSession()` + PIN `lock()` + `queryClient.clear()`. The future Logout button can just call it.
- Verified over HTTP: expired (signed with `expiresIn: -10`), garbage and missing token → code present; wrong PIN and wrong password → 401 without the code. Temp family deleted. Both workspaces typecheck; Prettier applied. **Not yet tested in the browser.**
